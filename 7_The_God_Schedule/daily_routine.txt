# THE THREE-PERSON GOD SCHEDULE

Use this as the default operating day. Shift times when client time zones require it, but preserve the blocks.

## 08:30–08:45 — HARD STAND-UP

A:
- pipeline
- calls
- proposals
- client risks

B:
- delivery milestone
- blockers
- technical risks

C:
- QA/release status
- proof
- internal system blockers

Every person states:
**Yesterday shipped / Today ships / Blocked / Risk**

No long discussion.

## 08:45–11:00 — PRIMARY WORK

### A — Revenue
- 20 prospect research
- 10 first contacts
- 10 follow-ups
- proposals/calls as required

### B — Delivery
- highest-value client milestone
- implementation
- integration
- deployment

### C — Product + QA
- feature/product work
- QA
- test automation/checklists
- demo/proof asset

## 11:00–11:20 — TECH + SALES SYNC

A brings only qualified opportunities.

B/C answer:
- feasibility
- timeline
- dependencies
- risk

No building before a real opportunity requires it.

## 11:20–13:00 — DELIVERY / SALES CALLS

A handles calls/proposals/client decisions.
B/C continue delivery.

If A has no call:
A continues outbound.

## 13:00–14:00 — BREAK

## 14:00–16:30 — DEEP DELIVERY

All three work on committed outcomes.

Avoid task switching.

## 16:30–17:00 — QA + REVIEW

C is release gate.
B fixes.
A checks scope/acceptance.

## 17:00–17:20 — OPERATIONS

A: CRM/pipeline/client status.
B: delivery board.
C: QA/proof/docs.

## 17:20–17:30 — TOMORROW

Each writes exactly one first physical action.

## Daily minimum

A:
- 10 first contacts
- 10 follow-ups
- pipeline updated
- sales/proposal work

B:
- one committed delivery milestone

C:
- one QA/product/proof milestone

Company:
- at least one shipped artifact
- no critical blocker hidden overnight

## When pipeline is empty

A does NOT start coding.

A increases prospecting.

B/C can build one reusable demo only after agreeing on the buyer/problem.

## When delivery is overloaded

B/C prioritize committed client work.
A protects communication, scope, and payment.
Do not solve overload by immediately hiring.
