# DEVELOPER HANDOFF SOP — INTERNAL

A sale becomes a build only after qualification and agreed payment terms.

## A -> B/C
A provides:
- business objective
- exact workflow
- approved deliverables
- exclusions
- acceptance criteria
- deadline
- client dependencies
- approved access
- known risks

## B owns
- architecture
- implementation plan
- integration
- deployment

## C owns
- test plan
- acceptance checks
- QA
- release evidence
- documentation

## Review rule
No person should be the only reviewer of their own critical production change.

If outside contractors are later added, they receive bounded tasks with a Definition of Done and evidence requirements.

The three-person team owns the client promise and final QA.
