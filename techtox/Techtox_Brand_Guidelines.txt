# FLOW VELLO BRAND/COMMUNICATION NOTE

This file previously described Techtox. That creates brand confusion.

## Canonical brand

**Flow Vello**

## Communication

Clear, technical when useful, business-first always.

Avoid:
- fake "enterprise" claims
- exaggerated ROI
- invented client results
- aggressive language toward prospects
- jargon without a business reason

## Visual principle

The website can be distinctive, but sales documentation should prioritize clarity:
Problem -> Process -> Solution -> Proof -> Next step.

## Naming rule

Do not use Techtox in Flow Vello proposals, outreach, onboarding or client-facing documentation unless a specific legal/business reason requires it.
