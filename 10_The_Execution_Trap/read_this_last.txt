# READ THIS WHEN THREE ENGINEERS START HIDING IN WORK

Three engineers can hide procrastination inside technical work.

Examples:
- rebuilding the website
- creating another framework
- comparing AI models
- creating 50 demos
- reorganizing GitHub
- polishing branding

Ask:

> Does this action increase qualified demand, paid delivery, or verified proof this week?

If no, stop.

## A
- identify 20 prospects
- send 10 first contacts
- send 10 follow-ups
- run calls/proposals
- update pipeline

## B
- select the highest-value committed delivery outcome
- define the smallest build
- implement
- test
- ship

## C
- define acceptance checks
- QA
- create proof/demo
- document
- remove one recurring delivery bottleneck

The team does not need another strategy document.

It needs evidence.
