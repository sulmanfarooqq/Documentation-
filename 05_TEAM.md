# THREE-PERSON OWNERSHIP
- **A — Revenue:** research, outreach, follow-ups, discovery, proposals, payment, client decisions.
- **B — Delivery:** technical discovery, architecture, integrations, build, deployment, reliability.
- **C — QA + Proof:** acceptance tests, edge cases, release checklist, demo evidence, documentation, case studies with permission.
- Daily: A sends 10 qualified contacts + 10 follow-ups; B ships one milestone; C completes one QA/proof milestone.
- Before build: A locks scope/payment; B confirms feasibility; C writes acceptance tests.
- During build: B builds; C tests; A resolves client decisions and protects scope.
- Before handoff: C signs off tests; B verifies deployment; A confirms acceptance/payment.
- One task = one owner; helpers do not create shared accountability.
- Stand-up: 10 minutes—shipped yesterday, output today, blocker, owner.
- Never let all three hide in engineering while nobody sells.
