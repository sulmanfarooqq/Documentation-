# Signal-to-Offer Match
Lead ads + manual routing → lead intake, assignment, CRM logging, and failure alerts.
CRM migration or duplicate entry → scoped field mapping and controlled sync.
Slow manual follow-up explicitly reported → one approved follow-up sequence with opt-out handling.
Operations hire for repetitive admin → ask which workflow is costly before proposing automation.
Broken form or integration publicly documented → reproduce safely, confirm owner, then scope repair.
Do not pitch chatbots, dashboards, websites, and agents all at once.
Offer only the smallest workflow that solves the verified problem.
