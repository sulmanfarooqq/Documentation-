# Minimum Tool Stack
Use a spreadsheet for leads, stages, evidence URLs, last touch, and next action.
Use email or the buyer's published business contact channel for personalized outreach.
Use the client's existing CRM and approved automation tools when feasible.
Use synthetic data in demos; never expose client data or credentials.
Add paid tools only when a client funds them or a measured bottleneck justifies cost.
Do not buy subscriptions to avoid the harder work of selling.
Document access, costs, limits, and failure handling before production deployment.
