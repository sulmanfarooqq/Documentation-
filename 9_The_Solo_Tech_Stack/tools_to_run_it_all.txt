# TEAM TECH STACK

The filename is retained for repository continuity. The operating model is now for three engineers.

## Minimum stack

- Lead research: LinkedIn, Google, public company sites
- Pipeline: simple CRM/Google Sheets
- Communication: business email + meeting tool
- Docs: shared documentation
- Code: GitHub
- Hosting: appropriate low-cost/free hosting during validation
- Automation: n8n/Make/Zapier/custom code based on requirements
- AI: existing tools where they create measurable value
- Project tracking: one Kanban/project board

## Engineering rules

- Git flow must be understandable to all three.
- Every production change is reviewable.
- Secrets never live in source control.
- Production access follows least privilege.
- Client environments remain separated.
- Shared credentials are avoided.
- Backups/rollback exist where the project requires them.

## Team rule

More tools do not solve unclear ownership.

Use the smallest stack that lets the team:
**sell -> build -> test -> deploy -> support -> measure.**

Do not buy software to compensate for an empty pipeline.
