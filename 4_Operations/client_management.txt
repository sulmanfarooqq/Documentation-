# CLIENT MANAGEMENT — SIMPLE VERSION

At Stage 1, complexity is the enemy.

## One source of truth

Use one project board and one client communication channel.

For each project track:
- Scope
- Tasks
- Owner
- Deadline
- Status
- Blockers
- Client approvals
- Links/access

Email is acceptable for formal communication. If a client uses WhatsApp, summarize important decisions in the project record so nothing is lost.

## Update rhythm

Send a short update at least twice per week:
- completed
- next
- blocked
- client action needed

Never make the client chase you for status.
