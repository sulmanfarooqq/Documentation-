# SCALING PATH — DO NOT SKIP STAGES

This file is deliberately less glamorous than a "million-dollar roadmap".

## Stage 0 — $0

Goal: first paid project.

Founder does sales + solution design + most delivery.

Target offer price: $150–$500.

## Stage 1 — $1–$3k cumulative revenue

Goal: repeat one offer.

Standardize:
- outreach
- discovery
- proposal
- onboarding
- build
- QA
- handoff
- testimonial request

Raise prices only when delivery is reliable.

## Stage 2 — $3–$10k/month

Goal: remove yourself from low-value execution.

Hire contractors for specific bottlenecks, not vague "developers".

Use fixed scopes and acceptance tests.

## Stage 3 — $10k+/month

Add project/account coordination when client communication and delivery coordination consume too much founder time.

Build a bench of specialists.

## Hiring trigger

Hire when:
- work is already sold
- the task is repeatable
- you know how to QA it
- contractor cost fits the project margin
- hiring increases capacity rather than hiding a sales problem

Revenue targets are not guarantees. The path depends on offer quality, market, conversion, delivery capacity and retention.
